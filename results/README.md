# Results

This directory stores figures generated by the notebooks.

Figures are **not tracked by git** by default (see `.gitignore`). Run the notebooks to regenerate them.

## Expected outputs

| Notebook | Figures |
|----------|---------|
| `01_SHCB_benchmark` | SHCB surface/contours, EGO convergence history, sampling trajectory, RMSE evolution, EGO vs static LHS comparison |
| `02_surrogate_benchmarking` | Parity plots (TR and PD × 6 models), RMSE bar charts |
| `03_optimisation` | TR/PD surrogate surfaces, parity plots, single-objective 3D plots, Pareto front |
| `04_EGO_convergence_analysis` | TR/PD convergence traces, LOO-RMSE traces, infill locations, EI landscape snapshots, EGO vs LHS data efficiency |
