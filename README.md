## Overview

This project develops a **surrogate-based optimisation framework** for an aerospace serpentine microchannel heat sink (MCHS). Starting from a 30-point CFD dataset, the framework compares four surrogate model families, validates an Efficient Global Optimisation (EGO) adaptive sampling strategy, and produces a Pareto front of optimal designs trading off **thermal resistance (TR)** against **pressure drop (PD)**.

The workflow demonstrates that machine-learning surrogates coupled with adaptive sampling can efficiently explore expensive, small-data engineering design spaces — a common constraint in aerospace CFD.

## Methodology

### 1. Surrogate Model Benchmarking (`02_surrogate_benchmarking.ipynb`)

Four surrogate families are implemented and compared on an 80/20 train/test split:

| Model | Notes |
|---|---|
| **Kriging (Gaussian Process)** | Best accuracy; provides predictive uncertainty for EGO |
| RBF Multiquadric | Strong interpolant; no uncertainty estimate |
| RBF Linear / Inverse Multiquadric | Decreasing accuracy |
| Neural Network (MLP) | Overfits on 30 points |
| Random Forest | Non-smooth; high RMSE on small datasets |

**Key result:** Kriging achieved the lowest mean RMSE across both TR and PD outputs and was selected as the primary surrogate.

### 2. Adaptive Sampling — EGO (`01_SHCB_benchmark.ipynb`)

EGO is first validated on the **Six-Hump Camelback (SHCB)** benchmark function, which has six local minima and two global minima at f ≈ −1.0316. Using 10 initial LHS points + 20 adaptive iterations (30 total evaluations):

- EGO converges to **f = −1.0279** (absolute error: 0.0037)
- Static LHS mean: **f = −0.9326** (absolute error: 0.099) — ~27× worse
- Distance to global minimum: EGO 0.024 vs static LHS 0.643

### 3. Surrogate-Based Optimisation (`03_optimisation.ipynb`)

Separate Kriging surrogates are trained for TR and PD, then optimised using:
- **Differential Evolution** — global search for single-objective anchors
- **Weighted-sum scalarisation** (50 weights, DE per weight) — Pareto front generation

| Design | G1 | G2 | TR (K/W) | PD (Pa) |
|---|---|---|---|---|
| Min TR | 1.000 | 1.000 | 0.1619 | 13868 |
| Min PD | 1.000 | 0.400 | 0.1862 | 12553 |
| **Balanced** | — | — | **0.1634** | **13622** |

The balanced design sits within 1% of the best thermal performance while increasing PD by only ~2%.

### 4. EGO Convergence Analysis (`04_EGO_convergence_analysis.ipynb`)

EGO applied directly to the MCHS dataset (normalised design space), comparing against 20 bootstrapped static LHS trials:
- TR converges within the first ~10 EGO iterations
- PD converges more gradually (shallower landscape)
- EGO consistently outperforms or matches static LHS for both objectives

## Getting Started

### Prerequisites

```bash
# Clone the repo
git clone https://github.com/YOUR_USERNAME/ml-surrogate-heatsink.git
cd ml-surrogate-heatsink
```

### Option A — conda (recommended)

```bash
conda env create -f environment.yml
conda activate mchs-surrogate
jupyter lab
```

### Option B — pip

```bash
pip install -r requirements.txt
jupyter lab
```

### Data

Place the CFD dataset file `heatsink.txt` in the `data/` directory. The file should be whitespace-delimited with four columns:

```
G1    G2    TR    PD
```

The notebooks reference this file as `/data/heatsink.txt` relative to the repo root (update the path variable at the top of each notebook if needed).

### Running the Notebooks

Run in order:

1. `02_surrogate_benchmarking.ipynb` — understand which surrogate is best
2. `01_SHCB_benchmark.ipynb` — validate EGO on a known function
3. `03_optimisation.ipynb` — generate the Pareto front
4. `04_EGO_convergence_analysis.ipynb` — analyse data efficiency

## Results Summary

- **Kriging** is the most accurate surrogate for small CFD datasets, outperforming neural networks and random forests that require larger training sets.
- **EGO with Expected Improvement** reliably finds near-global optima with 27× lower mean error than static Latin Hypercube Sampling at the same evaluation budget.
- **Adaptive sampling is more data-efficient** — particularly for the thermal objective, which has a sharper minimum.
- The **Pareto front** reveals a clear TR–PD trade-off: the balanced knee-point design achieves near-optimal thermal performance with only modest hydraulic penalty, making it the most practical choice for general aerospace application.
